V2New
基于 v2rayN 的定制分支，跟随上游自动更新

【首次使用】
1. 解压后双击 V2New.exe 启动。自包含发布，无需安装 .NET 运行时。
2. 首次运行需下载内核：菜单「检查更新」→ 勾选 Xray / sing-box / mihomo → 开始更新。
   也可以手动把内核放进程序目录下的 bin 文件夹。
3. 导入订阅或添加节点后即可使用。

【自动更新】
· 菜单「检查更新」里勾选程序本体，即可检查并升级到本仓库的最新版本。
· 版本由 CI 跟随上游自动构建：上游有新提交 → 自动合并 → 自动出包 → 客户端检测到新版本。
· 升级时会保留你的配置、订阅与节点数据（只覆盖程序文件，bin 目录下已有文件不覆盖）。

【新增功能】
· IP 地区列：显示节点出口 IP 的国家与城市，例如「美国 · 洛杉矶」
· IP 纯净度列：类型徽章 + 0-100 评分
    原生（绿）= 住宅 IP 且评分 >= 90
    住宅（绿/琥珀）= 普通宽带 IP
    机房（橙/红）= 数据中心、云服务器 IP
    代理（红）= 被标记为代理 / VPN / Tor
  分数越低说明该 IP 越容易被风控识别。
· 右键菜单「测试后自动排序」：关闭 / 按延迟 / 按速度
    一轮测速结束后自动把可用节点排到前面，未测或超时的沉底。
    同时提供「测试后自动移除无效节点」，默认关闭。

【配置项位置】
guiNConfig.json 中：
  speedTestItem.enableIpPurity              是否检测 IP 纯净度（默认开）
  speedTestItem.ipPurityUrl                 IP 质量接口地址
  speedTestItem.autoSortAfterTest           0 关闭 / 1 按延迟 / 2 按速度
  speedTestItem.autoRemoveInvalidAfterTest  测试后自动移除无效节点

【说明】
· 纯净度是基于公开 IP 标记的启发式评分，不等于风控厂商的真实风控分。
· 默认使用 ip-api.com 免费接口（HTTP，45 次/分钟）。若要更精细的欺诈分，
  可在设置中换成带 API Key 的付费接口。
· 本程序不包含任何推广链接。
